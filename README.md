# The Curious Archive ✳

Portfólio autoral de Khauê Almeida. Um site retrofuturista e editorial sobre inteligência artificial, dados, design e ideias que não cabem em caixas.

## Rodar localmente

Abra `index.html` no navegador. Como o site é feito somente com HTML, CSS e JavaScript, **não é necessário instalar Node, React ou outras dependências**. As fontes online são opcionais: há fontes de sistema como fallback.

## Personalizar

- Em `script.js`, preencha `SITE_CONFIG.githubUsername` com seu nome de usuário do GitHub.
- Em `index.html`, substitua descrições, projetos e informações que desejar. Atualmente, aparecem dois trabalhos: um experimento acadêmico e um conceito criativo. Não foram inventados links para repositórios.
- Em `style.css`, as variáveis `:root` definem a paleta. O botão **OUTRO UNIVERSO** alterna para uma segunda paleta.
- Em `favicon.svg`, edite o símbolo se quiser.

## Publicar em username.github.io

1. Crie um repositório **público** chamado **SEU_USUARIO.github.io** no GitHub, substituindo `SEU_USUARIO` pelo seu usuário real.
2. Envie todos os arquivos **desta pasta `site/`** para a **raiz** do repositório (não envie a pasta inteira como subpasta).
3. Em **Settings → Pages → Build and deployment**, escolha **Deploy from a branch**.
4. Escolha **main** e **/(root)** e salve.
5. Acesse `https://SEU_USUARIO.github.io` após a publicação. A atualização pode levar alguns minutos.

**Importante:** o repositório do perfil GitHub é diferente. Para o README especial, veja a pasta `profile/`.

## Acessibilidade

Inclui navegação via teclado, link para pular ao conteúdo, textos alternativos, feedback para filtros/tema, preferência por movimento reduzido e layout responsivo.
